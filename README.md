# K V Gokul — Portfolio

A responsive, dark premium-style personal portfolio built with HTML, CSS and JavaScript. It is ready to publish using GitHub Pages.

## Files
- `index.html` — portfolio content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and current year

## Before publishing
1. Open `index.html` and update the education line with your college name and expected graduation year.
2. Update the skills list to reflect technologies you can confidently use.
3. Update project status and descriptions as your projects progress.
4. Add a real resume PDF only after you have one ready. The current site does not claim a resume is attached.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `Gokuzz-Creation.github.io` only if you want the site at that exact account URL. Otherwise, create a repository named `portfolio`.
2. Upload all four files (`index.html`, `style.css`, `script.js`, `README.md`) to the repository's root folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then press **Save**.
6. Wait for the Pages deployment to finish. GitHub will show the published website address in Settings → Pages.

For a project repository named `portfolio`, the usual address is:
`https://gokuzz-creation.github.io/portfolio/`

For the account repository `Gokuzz-Creation.github.io`, the usual address is:
`https://gokuzz-creation.github.io/`
